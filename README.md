# How to Enlarge the Button Size of WinForms DateTimePickerAdv
This repository contains a sample that demonstrates how to customize and enlarge the drop‑down button size of the Syncfusion WinForms DateTimePickerAdv control. By default, the button size is fixed, but certain application scenarios—such as touch‑enabled interfaces or accessibility‑focused designs—require larger and more user‑friendly controls.

## Overview
The sample shows how to modify the appearance and layout of the DateTimePickerAdv control to increase the button size without affecting its core functionality. This helps improve usability, especially on high‑DPI displays or devices where precise mouse interaction may be challenging.

## What This Sample Demonstrates
How to access and customize the DateTimePickerAdv button
Techniques to increase the button size programmatically
Maintaining consistent layout and visual alignment
Improving usability for touch and accessibility scenarios

## Use Cases
Touch‑friendly WinForms applications
High‑DPI or kiosk‑based systems
Accessibility‑focused UI designs
Custom‑styled input controls

This sample serves as a practical reference for developers who need enhanced control over the visual behavior of the WinForms DateTimePickerAdv component.
